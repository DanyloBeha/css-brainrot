# How to rebuild everything

Raw data (`data/reddit_arctic/`, from `dataset-collection/arctic_download.py`) is never edited. Everything else is derived.

```bash
# once, from the repo root
uv venv --python 3.12 .venv && source .venv/bin/activate
uv pip install -r exploratory-data-analysis/requirements.txt
python -c "import nltk; nltk.download('vader_lexicon')"
playwright install chromium            # only for the PDF export

cd exploratory-data-analysis
python run_pipeline.py                 # clean -> aggregates -> text -> features -> events -> csv (about 8 min)
python tools/build_nb_01_overview.py && python tools/build_nb_02_text.py && python tools/build_nb_03_crisis.py
(cd notebooks && jupyter nbconvert --to notebook --execute --inplace 0*.ipynb)
python tools/insert_h4.py              # copies the H4 analysis into Ivan's section of eda.ipynb (touches nothing else)
python tools/assemble_eda.py           # optional: DRAFT of the full story in notebooks/99_full_story_draft.ipynb (never eda.ipynb)
```

| Folder | What is in it | In git |
| --- | --- | --- |
| `src/` | all logic: `io_reddit` (cleaning), `aggregates`, `textmining`, `events`, `sessions`, `figs_*` (one function per chart), `viz` (style), `export` | yes |
| `notebooks/` | working notebooks (01 overview, 02 text, 03 H4), generated by `tools/build_nb_*.py`; `99_full_story_draft` and `98_intermediate_pack_draft` are drafts of the merged story. `eda.ipynb` is the team notebook: only Ivan's H4 section is filled, by `tools/insert_h4.py`. After hand edits the notebooks are the source of truth | yes |
| `data/processed/` | row-level cleaned Parquet (`*.parquet`) and `derived/` (lexicon matches, per-comment features, a VADER label sample): contains comment text | **no** |
| `data/aggregates/` | small tables every chart reads from | yes |
| `data/external/` | World Uncertainty Index (monthly), Trends / YouTube / TikTok extracts when they exist; `raw/` holds downloads | extracts yes, `raw/` no |
| `figures/` | one PNG per chart id | yes |
| `outputs/` | PDFs and the CSV | `3_FightClub.csv` only (see `.gitignore`) |
